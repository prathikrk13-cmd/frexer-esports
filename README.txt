FREXER ESPORTS - STARTER PROJECT

This is the first visual prototype of your esports organisation app.
It is free static web app code and can be hosted on GitHub Pages at no cost for a public repository.

CURRENTLY INCLUDED:
- Responsive black / white / yellow design
- Home, teams, tournaments, lobby updates, results, leaderboard, social hub
- Admin dashboard placeholder
- Installable PWA foundation and basic offline caching

NOT CONNECTED YET:
- Real player accounts / login
- Secure admin login
- Database and editing tools
- Live updates
- APK packaging

IMPORTANT:
Do not publish passwords, private player data, or payment details in this static version.
The admin area is only a visual placeholder, not a secure admin system.

NEXT STEPS FROM AN ANDROID PHONE:
1. Download and extract this ZIP.
2. Open github.com in Chrome and sign in / create a free account.
3. Create a NEW PUBLIC repository named frexer-esports.
4. Upload the files from this ZIP into the repository root.
5. In the repository, open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Choose branch main and folder /(root), then Save.
8. Wait for GitHub Pages to publish the site. It will show the public website address in Settings > Pages.

After the site is published, open it in Chrome on Android. Use the browser menu > Add to Home screen (or Install app if shown).

This starter does not create an APK yet. We will add the real backend and test the app before attempting APK packaging.
